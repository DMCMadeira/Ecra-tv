⚠️ Abre com servidor local (só 1 vez)

Os vídeos do YouTube precisam de correr num servidor HTTP — não funcionam com file://.

Opção A — Python (recomendado):

cd pasta\do\ficheiro
python -m http.server 8080

Depois abre: http://localhost:8080/lpma_signage_dashboard.html

Opção B — VS Code: botão direito no ficheiro → "Open with Live Server"

  • Preme F para fullscreen
  • Preme R para forçar actualização da live
  • A actualização automática acontece todos os dias às 08:00
